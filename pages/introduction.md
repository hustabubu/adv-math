**问题一：为什么要学高等数学？**

<v-clicks depth="2">

1. **匀速**直线运动、**常力**做功、**均匀密度**物体的质量等问题。
- 如果运动的**速度变化**，怎么办？
- 如果不是常力，而是**变力**，怎么办？
- 如果物体的**密度不均匀**，怎么办？

2. **直**线的长度、矩形的面积、长方体的体积等问题。
- **曲**线的长度，怎么求？
- 平面上封闭**曲**线所围图形的面积，怎么求？
- 空间中**曲**面的面积？封闭**曲**面所谓的立体图形的体积，怎么求？

</v-clicks>

<span v-click='5'>几何图形问题可归结为函数问题，“**直**” $\sim$ “**不变**”、“**曲**” $\sim$ “**变**”。</span>

::right::

<v-click at='6'>

**中学知识解决问题的<span style="color:red">瓶颈</span>：** <span style="color:red">解决不了“**变**”问题</span>。
</v-click>

<span v-click='7' v-mark="{ at: 7, color: 'yellow', type: 'highlight' }">**怎么解决“变”的问题？**</span>

<span  v-click='8' v-mark="{ at: 8, color: 'yellow', type: 'highlight' }">**这就是高等数学要解决的。**</span>

**问题二：有了网上课程和 AI，能辅导我们学习很多知识，但为什么还要来教室上课？**

<v-clicks>

- 大家先问 AI：推荐一下高等数学的参考书；

</v-clicks>

<v-clicks>

- AI 的优点在哪里？
> **快、广，如同“房谋”。**

- AI 有什么不足？或者说我们需要做什么？
> **甄别、判断、决断，也就是我们需要“杜断”。**
</v-clicks>

::right::

<span v-click='8'>**AI 就是新时代的“房玄龄”，AI 的“谋”之快、之广，远超人类。**</span>

<span v-click='9'>**谁来当那个“杜如晦”？如何“杜断”？**</span>

<span  v-click='10' v-mark="{ at: 10, color: 'yellow', type: 'highlight' }">我们的高数课堂，就是“**杜如晦训练营**”。</span>

**这个‘断’的权力和能力，AI永远交不出**。 

因为“断”不需要数据堆砌，

它需要**数学直觉**、**底层逻辑**，以及**敢于为自己的选择担责的勇气**。”
</v-click>

<span v-click='0' v-mark="{ at: 0, color: 'yellow', type: 'highlight' }">**怎么练出“杜断”？**</span>

<span v-click='1' v-mark="{ at: 0, color: 'yellow', type: 'highlight' }">“**博学之，审问之，慎思之，明辨之，笃行之**”</span>

<v-clicks at='2'>

- **“博学”与“审问”**（情报搜集）：广泛吸收信息，并带着质疑精神追问细节。这是房玄龄**出谋划策的前提**，也是杜如晦**做出判断的素材**，缺此基础，谋断皆为空谈。
- **“慎思”**（周密筹划） → **对应“房谋”**：反复权衡各种可能性，设计出多套备选方案，推演利弊。这就是房玄龄“谋”的精华所在——**把“怎么干”想透**。
</v-clicks>

::right::

<v-clicks at='4'>

- **“明辨”**（清晰决断） → **对应“杜断”**：在众多方案和复杂变量中，精准辨别是非优劣，一针见血地拍板。这就是杜如晦“断”的功力——**决定“到底干哪个”**。
- **“笃行”**（坚定执行） → **对应“落实”**：决策做出后，忠实地去推行。这虽然是房杜二人合作后的落地环节，但“谋”和“断”的价值最终都要靠“行”来检验。
</v-clicks>

<span v-click='6' v-mark="{ at: 6, color: 'yellow', type: 'highlight' }">**学习数学的过程，就是在反复磨练这些技能。**</span>

<span v-click='7'>**如果学习高数局限于会做题，那么无异于缘木求鱼！**</span>
